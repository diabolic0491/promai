# PromAI

PromAI — специализированное web-приложение для предприятий Республики Беларусь.

## Цель MVP

- ведение карточек контрагентов;
- загрузка и хранение договоров;
- предварительный ИИ-анализ договорных рисков;
- дальнейшая генерация договоров по утверждённым шаблонам.

## Статус

Backend MVP: контрагенты, договоры, ТЗ, DOCX-генерация и
ролевая модель доступа.

## Структура проекта

- `backend` — серверная часть и API;
- `frontend` — пользовательский интерфейс;
- `infrastructure` — конфигурация развёртывания;
- `docs` — техническая документация.

## Безопасность

В репозиторий запрещено добавлять:

- реальные договоры;
- персональные данные;
- пароли;
- API-ключи;
- сертификаты ЭЦП;
- файлы `.env`.

## Роли и доступ

В MVP используются только две роли:

- `admin` — полный рабочий доступ, управление пользователями,
  профилем организации и шаблонами документов;
- `manager` — работа с контрагентами, договорами и ТЗ, просмотр
  и использование активных шаблонов.

Роль наблюдателя в MVP отсутствует.

Маршруты `/health` и `/` публичны. Остальные рабочие маршруты
требуют JWT access-токен. Аутентификация доступна через:

- `POST /auth/login`;
- `POST /auth/refresh`;
- `POST /auth/logout`;
- `GET /auth/me`.

Управление пользователями выполняется администратором через
`/users`.

## Версии документов договоров

Каждая успешная генерация DOCX сохраняется как отдельная
неизменяемая версия. Для версии фиксируются шаблон, снимок
исходных данных, автор, размер файла и контрольная сумма SHA-256.

- `GET /contracts/{contract_id}/versions` — список версий;
- `GET /contracts/{contract_id}/versions/{version_number}/download`
  — скачивание выбранной версии;
- `GET /contracts/{contract_id}/download` — скачивание последней
  версии.

## Первичная настройка RBAC

Сгенерируйте секрет и добавьте его в `.env`:

```bash
openssl rand -hex 32
```

Значение должно быть записано как `AUTH_SECRET_KEY`. Затем
пересоберите backend, примените миграцию и создайте первого
администратора:

```bash
docker compose up -d --build backend
docker compose exec backend python -m alembic upgrade head
docker compose exec backend \
  python -m app.scripts.create_admin --username admin
```

Пароль запрашивается интерактивно и не передаётся в аргументах
командной строки. Команда первоначального создания работает,
только пока таблица пользователей пуста.
